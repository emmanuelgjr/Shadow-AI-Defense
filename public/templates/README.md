# Templates and comms

This directory hosts downloadable Word templates referenced by `/comms` and
`/policy` pages.

Filename convention matches the comms IDs in `/src/pages/comms.astro`.

Five of the ten comms templates are written and generated by
`scripts/generate-comms.ts`; run `npx tsx scripts/generate-comms.ts` to
rebuild them. The other five are still being drafted and are shown on
`/comms` as "In drafting" rather than linked.

When a new template is finished, add it to `generate-comms.ts`, regenerate,
and flip its `available` flag in `/src/pages/comms.astro`. Both halves are
enforced by `tests/comms-templates.test.ts`, which fails if the page offers
a download whose `.docx` is missing.

The full Shadow AI policy text lives in `/src/pages/policy.astro` and is
displayed inline (it does not require download).
